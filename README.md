# DashStar

**Minecraft 1.21.11 / Fabric / Meteor Client 末地鞘翅自动化插件。**

自动找船、收集鞘翅、补给、存储、丢垃圾，以及长距离飞行控制。


> 本项目基于 **GNU GPLv3** 开源。  
> 请只从官方 GitHub Releases 或官方 QQ 群获取发布文件。

---

## 功能

### 自动找船与收集

- 基于种子的末地城 / 末地船预测
- 自动搜索、飞往、降落
- 自动定位展示框并收集鞘翅
- 空船、偏移展示框、未加载区块的处理
- 26.3 末地地形高度修正

### 补给与存储

- 自动把鞘翅存入潜影盒
- 自动补充烟花
- 自动修复鞘翅
- 容器放置与回收
- 关闭模块时保留待存计数

### 飞行与安全

- Pitch-40 风格远距离巡航
- 可配置最低 / 最高飞行高度
- 紧急拉升，可配置触发高度与向上角度
- 船头捷径与垂直离船
- 降落点支撑检查
- 关闭功能时取消残留任务

### 战斗辅助

- 可选择攻击目标，包括潜影弹
- 面向服务端移动校验设计转头与攻击顺序
- 寻路继续时仍可保持攻击
- 容器界面打开时不攻击

### 集结令

在聊天栏发送：

```text
挂翅集结
```

插件会从内置回复库中随机回复一条。
